# 게임 내 키보드
이 게임에는 코드를 쓰기 위한 전용 키보드가 들어있어요. Python에 필요한 기호가 모두 한 페이지에 모여 있고, 스와이프로 커서를 옮기고, 텍스트를 선택하고, 코드 자동 완성을 고를 수 있어서 코드의 작은 지점을 정확히 눌러야 할 일이 없어요.

기기 자체 키보드를 쓰고 싶다면 옵션에서 "키보드 종류"를 "시스템"으로 설정하세요. 하드웨어 키보드가 연결되어 있으면 항상 그것을 대신 사용하고, 연결을 해제하면 게임 내 키보드가 다시 나타나요.

## 입력
**괄호와 따옴표**: `()`, `[]`, `{}`, `"` 키는 짝을 함께 입력하고 커서를 그 사이에 둬요. 텍스트를 선택한 상태라면 대신 그것을 감싸고 선택을 유지해서 다시 감쌀 수 있어요. 괄호 키를 잠시 누르고 있으면 여는 괄호나 닫는 괄호만 있는 팝업이, `"` 키를 누르고 있으면 작은따옴표 팝업이 나타나니, 원하는 쪽으로 밀고 손을 떼세요.

**Tab**: 한 단계 들여써요. 여러 줄을 선택했으면 모두 들여써요. Shift + Tab은 반대로 들여쓰기를 한 단계 줄여요.

**주석**(`#`): 현재 줄이나 선택한 모든 줄을 주석 처리하고, 이미 주석이면 해제해요.

**실행 취소, 다시 실행, 복사, 붙여넣기**는 예상대로 동작해요. 복사와 붙여넣기는 기기의 클립보드를 사용하므로 다른 앱의 코드를 붙여넣을 수 있어요. 다시 실행, 복사, 붙여넣기는 할 일이 없을 때 흐리게 표시돼요.

## 커서 이동
키보드에서 스와이프하면 커서가 움직여요. Shift와 삭제를 제외한 아무 키나 괜찮아요. 손가락을 대고 있는 동안 키보드가 트랙패드가 돼요. 옆으로 스와이프하면 한 글자씩, 위아래로 스와이프하면 줄이 바뀌어요. 빠른 스와이프는 느린 스와이프보다 멀리 가서, 휙 넘기면 멀리 이동하고 천천히 조심스럽게 스와이프하면 한 번에 정확히 한 글자씩 움직여요.

## 텍스트 선택
한 손가락으로 Shift를 누른 채 다른 손가락으로 스와이프하면 커서부터 텍스트가 선택돼요. 스와이프하던 손가락을 떼고 다시 스와이프하면 같은 선택 범위를 늘릴 수 있어요. 스와이프 도중에 Shift를 누르거나 떼면 선택과 일반 커서 이동이 전환돼요.

무언가를 선택하면 위의 키로 복사, 삭제, 괄호로 감싸기, 들여쓰기, 주석 처리를 할 수 있어요.

## 코드 자동 완성
입력하는 동안 자동 완성 목록이 나타나요. 위아래로 스와이프해서 목록을 이동한 다음 Tab을 누르거나 항목을 탭해서 삽입하세요. 지금까지 입력한 내용과 일치하면 Return으로도 삽입돼요. 그렇지 않으면 Return은 목록을 닫고 새 줄을 시작해요. 옆으로 스와이프하면 아무것도 삽입하지 않고 목록을 닫아요.

## 배열
"키보드 배열" 옵션으로 QWERTY, QWERTZ, AZERTY 중에서 고를 수 있어요.

## 느낌
옵션의 "키 피드백"이 키보드의 느낌과 소리를 정해요. **클릭음 + 진동**은 키를 누를 때마다 기계식 키 소리를 내고 진동하며, 스와이프하는 동안 커서가 한 칸 움직일 때마다 짧게 떨려요. **진동**은 소리 없이 같은 일을 하고, **클릭음**은 소리만 내고, **무음**은 둘 다 하지 않아요. **시스템 클릭음** 종류는 기계식 소리 대신 기기 키보드의 클릭 소리를 사용해요.
