# 주석
주석은 실행 중에 무시되는 코드의 일부예요.
주석은 `#`로 추가할 수 있어요. 같은 줄에서 `#` 뒤에 있는 모든 내용은 주석으로 처리되어 무시돼요.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
#이것은 주석입니다
#harvest()
}}

코드에 메모를 추가하거나, 코드를 삭제하지 않고 일시적으로 비활성화할 때 유용할 수 있어요.

함수 정의 바로 앞줄의 주석은 함수 이름 위에 마우스를 올렸을 때 표시되는 정보의 일부가 돼요.
