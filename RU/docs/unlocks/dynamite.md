# Динамит

Революционная взрывчатка, оставленная предыдущими шахтерскими экспедициями. К счастью (или к сожалению), твой бур идеально подходит для подрыва динамита, уничтожающего все блоки вокруг.

Чтобы безопасно добывать динамит, найди двойной пласт из `Grounds.Dynamite` и `Grounds.Soot`. Верхний динамитный грунт состарился, поэтому некоторые его блоки можно безопасно бурить. Но часть зарядов все еще активна и взорвется при бурении.

Сможешь найти и пробурить все блоки-пустышки, оставив только активные заряды? Когда динамитный пласт исчезнет, каждый активный блок, окруженный только другими активными блоками или сажей, даст дополнительный динамит.

К счастью, расположенные ниже блоки сажи помогут: они определяют количество соседних динамитных блоков с активными зарядами. Какие именно блоки активны, они не сообщат — только общее число, поэтому придется сопоставить показания нескольких блоков сажи.

Вызов `measure()` на блоке сажи возвращает количество мин в восьми соседних клетках динамитного пласта выше. Значение может быть от `0` (активных мин нет) до `8` (активная мина есть у каждого соседа).

Первый пробуренный блок динамитного пласта всегда оказывается пустышкой. Каждый добытый блок дает немного динамита. Когда пласт уничтожается — после успешной добычи всех пустышек или случайного попадания в активный заряд, — ты также получаешь количество динамита, равное квадрату числа полностью открытых активных блоков.

Если пробурить активный динамит, оба пласта взорвутся. Это можно проверить с помощью `get_ground_type()` после бурения `Grounds.Dynamite`. Если грунт не `Grounds.Soot`, решить головоломку не удалось. Если же пробурить последний неактивный динамитный блок, все динамитные блоки исчезнут, а ты получишь максимальный урожай за головоломку. Пласт сажи останется, но `measure()` вернет `None`, показывая, что головоломка успешно решена.

`# Пробурить динамитный блок и проверить состояние головоломки
def dig_dynamite():
    dig()
    if get_ground_type() != Grounds.Soot:
        # Пробурен активный динамит, головоломка провалена
        return False
    elif measure() == None:
        # Пробурен последний блок-пустышка, головоломка решена
        return True
    else:
        # При измерении получено число, головоломка продолжается
        return None
`

С глубиной растет число активных мин в динамитном пласте, а вместе с ним и сложность их поиска.

Собранный динамит можно применить командой `use_item(Items.Dynamite)`: он взорвется прямо под дроном.

Улучшай динамит, чтобы получать больше при бурении динамитных блоков и полном открытии активных зарядов. Каждое улучшение также повышает энергию взрыва динамита на 30%.
