# Горное дело

Дрон получил примитивный бур, позволяющий искать сокровища под землей.

Команда `dig()` позволяет пробурить блок под дроном.

# Бур

По мере углубления блоки становятся тверже, и бурение занимает больше времени. К счастью, бур можно улучшать!

С помощью `get_hardness()` можно проверить твердость блока под дроном. Встретив особенно твердые блоки, иногда лучше обойти их и продвигаться быстрее:

`while True:
        if get_hardness() < 5:
                dig()
        else:
                move(East)`

Конечно, с глубиной блоки становятся все тверже, поэтому эта стратегия помогает лишь до определенного момента.

## Обвалы

При бурении вниз окружающие блоки обваливаются. Четыре соседних с дроном блока уничтожаются всегда. Затем обвал распространяется в зависимости от устойчивости грунта. Блок с устойчивостью 1, например луг, выдерживает перепад высоты в 1 блок. Иными словами, если по вертикали или горизонтали с лугом соседствует блок, координата Z которого ниже на 2 или более, луг будет уничтожен.

Устойчивость блока указана во всплывающей подсказке.

При обвале блока уничтожаются и все блоки над ним. Ресурсы даются только за блоки, которые дрон пробурил напрямую, поэтому уничтоженные обвалом блоки ничего не приносят.
