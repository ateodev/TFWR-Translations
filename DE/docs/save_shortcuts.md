# Kopien mit Kurzbefehlen
Die App Kurzbefehle kann deine Spielstände jedes Mal, wenn du das Spiel verlässt, an einen Ort deiner Wahl kopieren, etwa in iCloud Drive. Das läuft von selbst, ohne Nachfrage. Das gehört zur Vollversion.

## Einrichten
1. Tippe in **Kurzbefehle** auf +, um einen neuen Kurzbefehl anzulegen, tippe oben rechts auf **Bearbeiten** und füge die Aktion **Neuesten Spielstand holen** des Spiels hinzu.
2. Füge **Datei sichern** hinzu und tippe auf ihren Pfeil. Schalte **Nach Speicherort fragen** aus, wähle einen Ordner und schalte **Überschreiben, falls Datei besteht** ein.
3. Tippe unten auf **Suchen**, dann auf **Automation**, und wähle unter **Apps** die Zeile **App**.
4. Tippe in der Zeile, die erscheint, auf **App** und wähle das Spiel, dann tippe auf **Geöffnet** und wähle **Geschlossen**.

Vor iOS 27 legst du die Automation stattdessen im Tab **Automation** an: Wähle **App**, das Spiel, nur **geschlossen wird** und **Sofort ausführen**, und gib ihr die Aktionen aus Schritt 1 und 2. Unter iOS 16 schaltest du stattdessen **Vor Ausführen bestätigen** aus.

Jede Kopie ist ein Zip mit dem Namen ihres Spielstands, also behältst du von jedem Spielstand eine aktuelle Kopie.

## Ältere Kopien behalten
Setze die Variable **Aktuelles Datum** in den Ordnerpfad von **Datei sichern**. Kopien von einem anderen Datum landen dann in einem eigenen Ordner, und die älteren bleiben.

## Weitere Aktionen
**Spielstand holen** holt einen Spielstand über seinen Namen. **Spielstände holen** holt jeden Spielstand oder nur die, die sich seit einem Datum geändert haben.

## Eine Kopie zurückholen
Die Aktionen kopieren deine Spielstände nur hinaus. Um eine Kopie zurückzuholen, drücke im Ladebildschirm „Import“ und wähle ihr Zip.

Die Cloud-Speicherung hält deine Geräte auf demselben Fortschritt. Eine Kopie aus Kurzbefehle ist deine eigene Datei, abgelegt, wo du willst, als Verlauf oder für das PC-Spiel.
