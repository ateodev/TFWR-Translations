# Import und Export
Du kannst einen Spielstand als Datei aus dem Spiel mitnehmen und einen hereinholen. Beides gehört zur Vollversion: In der Testversion öffnet ein Druck auf eines davon das Fenster, in dem du sie bekommst.

## Export
Tippe im Ladebildschirm auf die drei Punkte auf der Karte eines Spielstands und wähle „Exportieren“. Das Spiel macht ein Zip aus diesem Spielstand, und du wählst, wo es gespeichert wird.

Behalte es als eigene Kopie, oder nimm den Spielstand ins PC-Spiel mit: Entpacke es in einen eigenen Ordner im Saves-Ordner des PC-Spiels.

<shortcuts>Die App Kurzbefehle kann das auch jedes Mal für dich erledigen, wenn du das Spiel verlässt: [Kopien mit Kurzbefehlen](docs/save_shortcuts.md)
</shortcuts>
## Import
Drücke im Ladebildschirm auf „Import“ und wähle ein Zip eines Spielstands. Auf manchen Geräten kannst du auch den Ordner eines Spielstands wählen. Ein Spielstand darf bis zu 1 MB groß sein. Ein Import legt immer einen neuen Spielstand an und ersetzt nie einen.

Wenn ein Spielstand nicht so hereinkommen kann, wie er ist, sagt dir der Ladebildschirm warum:

**Bitte aktualisiere das Spiel**: Der Spielstand stammt aus einer neueren Version des Spiels. Aktualisiere das Spiel auf diesem Gerät, um ihn zu importieren.

**Dieser Spielstand stammt aus einer älteren Version**: Aktualisiere das Spiel auf deinem PC, lade diesen Spielstand dort und speichere ihn einmal. Kopiere ihn dann auf dieses Gerät und importiere ihn erneut.

**Dieser Spielstand wurde mit Änderungen importiert**: Der Spielstand enthielt Freischaltungen, Gegenstände oder Daten, die diese Version des Spiels nicht kennt oder nicht erlaubt. Sie wurden weggelassen oder gesenkt, und der Hinweis zählt auf, was sich geändert hat.

## Cloud-Speicherung
Die Cloud-Speicherung hält deine Geräte auf demselben Fortschritt. Eine exportierte Datei gehört dir allein und liegt dort, wo du sie ablegst.
