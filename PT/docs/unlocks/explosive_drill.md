# Broca explosiva

Chamar dig() com a broca explosiva equipada consome uma Items.Dynamite e provoca uma explosão parecida com use_item(Items.Dynamite). Porém, ao contrário de uma explosão de dinamite comum, ela coleta todos os blocos atingidos pela explosão!

Você só tem uma broca explosiva, então apenas um drone pode equipá-la por vez.
