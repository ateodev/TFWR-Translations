# Comentários

Comentários são partes do código que são ignoradas durante a execução.
Comentários podem ser adicionados usando `#`. Qualquer coisa na mesma linha após o `#` é um comentário e será ignorada.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
#isto é um comentário
#harvest()
}}

Isso pode ser útil para adicionar anotações ao código ou desativar partes dele temporariamente sem excluí-las.

Um comentário na linha anterior à definição de uma função passa a fazer parte das informações exibidas ao passar o cursor sobre o nome da função.
