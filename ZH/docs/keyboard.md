# 游戏内键盘
游戏自带一个用于编写代码的键盘。它把 Python 所需的全部符号放在同一页上，并且可以通过滑动来移动光标、选择文本和选取代码补全，这样你就再也不用费力去点代码里的某个小位置了。

如果你更想使用设备自带的键盘，请在选项中把“键盘类型”设为“系统”。连接了实体键盘时总是优先使用实体键盘，断开后游戏内键盘会重新出现。

## 输入
**括号和引号**：`()`、`[]`、`{}` 和 `"` 键会插入成对的符号并把光标放在中间。如果你选中了文本，它们会把文本包起来并保持选中状态，方便你再次包裹。长按括号键片刻，会弹出只含左括号或右括号的选项，滑到想要的那个再松开。

**Tab**：缩进一级。选中多行时会全部缩进。Shift + Tab 则是减少一级缩进。

**注释**（`#`）：注释掉当前行或所有选中的行，如果已经是注释则取消注释。

**撤销、重做、复制和粘贴**的用法和你想的一样。复制和粘贴使用设备的剪贴板，所以你可以从其他应用粘贴代码。重做、复制和粘贴在没有可操作内容时会变暗。

## 移动光标
在键盘上滑动可以移动光标。除了 Shift 和删除键，任何按键都可以：只要手指按住，键盘就会变成触控板。横向滑动每次移动一个字符，上下滑动可以换行。快速滑动比慢速滑动走得更远，所以轻轻一甩可以移动很长距离，而缓慢仔细地滑动则每步正好移动一个字符。

## 选择文本
用一根手指按住 Shift，再用另一根手指滑动，就可以从光标处开始选择文本。你可以抬起滑动的手指再次滑动，以扩展同一段选区。在滑动过程中按下或松开 Shift，可以在选择和普通光标移动之间切换。

选中内容后，你可以用上面的按键复制、删除、加括号、缩进或注释它。

## 代码补全
输入时会弹出一个补全列表。上下滑动可以在列表中移动，然后按 Tab 或点按条目来插入它。如果条目和你已输入的内容匹配，按 Return 也会插入它。否则 Return 会关闭列表并开始新的一行。横向滑动可以关闭列表而不插入任何内容。

## 布局
“键盘布局”选项可以在 QWERTY、QWERTZ 和 AZERTY 之间切换。

## 手感
选项中的“按键反馈”决定键盘的手感和声音。**按键音 + 振动**会在每次按键时播放机械键盘按键声并振动，滑动时每移动一步光标还会轻微振动一下。**振动**效果相同但没有声音，**按键音**只播放声音，**静音**两者都没有，而**系统按键音**的各个变体则使用设备键盘自带的按键声代替机械键盘声。
