# 注释

被注释的内容，在程序运行期间不会被执行。

可以使用 `#` 来添加注释。`#` 之后的所有内容都是注释，不会被程序执行。

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
#这是一条注释
#harvest()
}}

注释可以在代码中添加笔记，或者在不删除代码的情况下暂时禁用部分代码，用来调试你编写的程序。

在函数定义前一行添加注释，该注释会出现在鼠标悬停于函数名时显示的信息中。
