# ゲーム内キーボード
このゲームには、コードを書くための専用キーボードが付いています。Pythonに必要な記号がすべて1ページに収まっていて、カーソルの移動、テキストの選択、コード補完の選択をスワイプで行えるので、コードの中の小さな場所を狙ってタップする必要はありません。

端末のキーボードを使いたい場合は、設定で「キーボードの種類」を「システム」にしてください。物理キーボードを接続しているときは常にそちらが使われ、取り外すとゲーム内キーボードが戻ってきます。

## 入力
**括弧と引用符**：`()`、`[]`、`{}`、`"` のキーはペアを挿入し、その間にカーソルを置きます。テキストを選択している場合は、代わりにそれを囲み、選択したままにするので、さらに囲むこともできます。括弧のキーを少し長押しすると、開き括弧または閉じ括弧だけのポップアップが出るので、欲しい方にスライドして指を離してください。

**Tab**：1段階インデントします。複数行を選択していればすべてをインデントします。Shift + Tab は逆にインデントを1段階減らします。

**コメント**（`#`）：現在の行、または選択したすべての行をコメントアウトし、すでにコメントアウトされていれば解除します。

**元に戻す、やり直す、コピー、貼り付け**は期待どおりに動きます。コピーと貼り付けは端末のクリップボードを使うので、他のアプリからコードを貼り付けられます。やり直す、コピー、貼り付けは、やることがないときは薄く表示されます。

## カーソルの移動
キーボードの上でスワイプするとカーソルが動きます。ShiftとDelete以外ならどのキーでも構いません。指を置いている間、キーボードはトラックパッドになります。横にスワイプすると1文字ずつ、上下にスワイプすると行が変わります。速いスワイプは遅いスワイプより遠くまで進むので、さっと払えば大きく移動し、ゆっくり慎重にスワイプすれば1ステップにつきちょうど1文字ずつ動きます。

## テキストの選択
片方の指でShiftを押さえたまま、もう片方の指でスワイプすると、カーソルの位置からテキストを選択できます。スワイプしている指を離してもう一度スワイプすると、同じ選択範囲を広げられます。スワイプの途中でShiftを押したり離したりすると、選択と通常のカーソル移動が切り替わります。

何かを選択したら、上のキーでコピー、削除、括弧で囲む、インデント、コメントアウトができます。

## コード補完
入力中に補完候補のリストが表示されます。上下にスワイプしてリストを移動し、Tabを押すか項目をタップして挿入します。入力済みの内容と一致していればReturnでも挿入できます。一致しない場合、Returnはリストを閉じて新しい行を始めます。横にスワイプすると、何も挿入せずにリストを閉じます。

## 配列
「キーボード配列」の設定で、QWERTY、QWERTZ、AZERTYを切り替えられます。

## 操作感
設定の「キーの反応」で、キーボードの感触と音を決めます。**クリック音 + 振動**はキーを押すたびにメカニカルキーの音を鳴らして振動し、スワイプ中はカーソルが1つ動くごとに小さく振動します。**振動**は音なしで同じことをし、**クリック音**は音だけを鳴らし、**無音**はどちらもしません。**システム音**の各種類は、メカニカルキーの音の代わりに端末のキーボードのクリック音を使います。
