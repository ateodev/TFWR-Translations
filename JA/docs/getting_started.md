# はじめに
<desktop>このウィンドウには、ゲーム内のすべてに関する情報が含まれています。

ウィンドウの灰色の部分をドラッグアンドドロップして、ウィンドウを移動できます。
ウィンドウの外側のどこかをドラッグして、カメラを動かすことができます。

プログラミングを始めるには、クリックして[最初のプログラム](docs/first_program.md)ページに移動してください。

画面の右上隅にあるボタンをぜひチェックしてください。ボタンにカーソルを合わせると、その機能説明のツールチップが表示されます。そのうちの1つは技術ツリーを開きます！
</desktop>
<mobile>このウィンドウには、ゲーム内のすべてに関する情報が含まれています。

ウィンドウは画面いっぱいに開きます。ウィンドウのヘッダーにあるボタンで小さなウィンドウに戻したり、再び画面いっぱいに広げたりできます。小さなウィンドウは灰色の部分をドラッグして移動できます。
ウィンドウの外側のどこかをドラッグしてカメラを動かし、2本の指でズームできます。

プログラミングを始めるには、リンクをタップして[最初のプログラム](docs/first_program.md)ページに移動してください。

画面の下端にあるボタン（端末を横向きに持っているときは右上隅）をぜひチェックしてください。タップして何をするか試してみましょう。そのうちの1つは技術ツリーを開きます！
</mobile>
