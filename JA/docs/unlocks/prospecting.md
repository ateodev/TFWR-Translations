# 鉄の探査

鉄の鉱脈はなかなか見つからないことがあります。手当たり次第に掘って偶然見つけることもできますが、もっとよい方法があります。鉄は磁性を持つので、遠くから探せるのです。

`prospect_iron()` コマンドがその役割を果たします。`prospect_iron()` は、最も近い鉄鉱石に一歩近づくためにドローンが進むべき方角（`North`、`East`、`South`、`West`）を返します。実行には石炭を1個消費します。

ドローンがすでに最も近い鉄鉱石の真上にいる場合、石炭が足りない場合、または範囲内に鉄がない場合、`prospect_iron()` は `None` を返します。

次のコードで、次の鉄鉱石に一歩近づけます：

`if prospect_iron() != None:
    move(prospect_iron())
`

このコードでは `prospect_iron()` を2回呼び、石炭を2個消費します。変数を使って最適化するとよいでしょう。

最も近い鉄鉱石は、ドローンが移動するのに必要な歩数で判定されます。ドローンから東に2ブロック、北に3ブロックの位置に鉄があるなら、到達するには5歩必要なので、距離は5と数えます。

掘ることも1歩として数えます。その鉄がさらに地下7ブロックの深さに埋まっているなら、真上までの移動に5歩、到達するまでに7回掘るので、距離は12になります。
