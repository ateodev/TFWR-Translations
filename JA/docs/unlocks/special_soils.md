# パーライトと壌土

通気性がよい土や養分の豊富な土では、収穫量が増える植物があります。このアンロックでは、地下にパーライトと壌土（`Grounds.Perlite` と `Grounds.Loam`）という2種類のブロックが追加されます。

これらのブロックは粘土と同じように、地下に薄い層として現れます。

パーライトは通気性のよい土を好むサボテン、竹、茂み、木に適しています。これらの植物をパーライトに植えると、収穫量が2倍になります。

壌土はニンジンとヒマワリに適しています。ここに植えると収穫量が2倍になります。

パーライトと壌土には、適した作物を植える前に `till()` を呼ぶ必要がないという利点もあります。
