# パーライトと壌土

このアンロックでは、地下にパーライトと壌土（`Grounds.Perlite`と`Grounds.Loam`）という2つの新しいブロックの種類が追加されます。これらの土壌に植えた作物を収穫すると、収穫量が2倍になります。

パーライトと壌土は粘土と同じように地下に薄い層として現れますが、粘土より少し珍しいです。

パーライトは通気性のよい土壌を好むサボテン、竹、茂み、木に適しています。これらの植物をパーライトに植えると、収穫量が2倍になります。

壌土はニンジンとヒマワリに適しています。これらを壌土に植えると収穫量が2倍になります。

パーライトと壌土には、すぐに植え付けができるというもう一つの利点もあります。`Grounds.Grassland`の場合は、まず`till()`で`Grounds.Soil`に変える必要があります。
