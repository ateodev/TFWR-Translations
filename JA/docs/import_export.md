# インポートとエクスポート
セーブをファイルとしてゲームの外に持ち出したり、ゲームに取り込んだりできます。どちらも製品版の機能です。無料体験版では、どちらを押しても製品版を入手できるウィンドウが開きます。

## エクスポート
ロード画面でセーブのカードにある3つの点をタップし、「エクスポート」を選びます。ゲームがそのセーブを zip にまとめ、保存先はあなたが選びます。

自分用のコピーとして取っておくことも、PC 版のゲームにセーブを持っていくこともできます。PC 版ゲームの Saves フォルダーの中に専用のフォルダーを作り、そこに展開してください。

<shortcuts>ショートカット App を使えば、ゲームを終了するたびにこれを自動で行うこともできます：[ショートカットでコピー](docs/save_shortcuts.md)
</shortcuts>
## インポート
ロード画面で「インポート」を押し、セーブの zip を選びます。デバイスによっては、セーブのフォルダーも選べます。セーブは 1 MB まで取り込めます。インポートは必ず新しいセーブを作り、既存のセーブを置き換えることはありません。

セーブをそのまま取り込めないときは、ロード画面が理由を教えてくれます。

**ゲームを更新してください**：このセーブはゲームの新しいバージョンで作られています。インポートするには、このデバイスのゲームを更新してください。

**このセーブは古いバージョンのものです**：PC のゲームを最新版に更新し、そこでこのセーブを読み込んで一度保存してください。その後、このデバイスにコピーして、もう一度インポートしてください。

**このセーブは変更を加えてインポートされました**：このバージョンのゲームが知らない、または認めていないアンロック、アイテム、データがセーブに含まれていました。それらは省かれるか引き下げられ、お知らせに変更点が一覧で表示されます。

## クラウドセーブ
クラウドセーブは、あなたのデバイスを同じ進行状況にそろえます。エクスポートしたファイルはあなただけのもので、好きな場所に保管できます。
