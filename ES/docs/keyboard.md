# Teclado del juego
El juego incluye su propio teclado para escribir código. Reúne todos los símbolos que Python necesita en una sola página y te permite mover el cursor, seleccionar texto y elegir opciones de autocompletado deslizando el dedo, para que nunca tengas que apuntar a un punto diminuto de tu código.

Si prefieres usar el teclado de tu dispositivo, pon "Tipo de teclado" en "Sistema" en las opciones. Un teclado físico conectado se usa siempre en su lugar, y el teclado del juego vuelve cuando lo desconectas.

## Escritura
**Paréntesis y comillas**: las teclas `()`, `[]`, `{}` y `"` insertan la pareja y colocan el cursor en medio. Si tienes texto seleccionado, lo envuelven y lo mantienen seleccionado, para que puedas envolverlo otra vez. Mantén pulsada una tecla de paréntesis un momento para obtener una ventana emergente con solo el de apertura o el de cierre, o la tecla `"` para una comilla simple; desliza hasta el que quieras y suelta.

**Tab**: indenta un nivel. Con varias líneas seleccionadas las indenta todas. Shift + Tab quita un nivel de indentación en su lugar.

**Comentario** (`#`): comenta la línea actual, o todas las líneas seleccionadas, y las descomenta cuando ya lo están.

**Deshacer, rehacer, copiar y pegar** funcionan como cabe esperar. Copiar y pegar usan el portapapeles de tu dispositivo, así que puedes pegar código de otras aplicaciones. Rehacer, copiar y pegar aparecen atenuados cuando no tienen nada que hacer.

## Mover el cursor
Desliza el dedo sobre el teclado para mover el cursor. Vale cualquier tecla excepto Shift y Borrar: el teclado se convierte en un panel táctil mientras tengas el dedo apoyado. Desliza de lado para moverte carácter a carácter y hacia arriba o abajo para cambiar de línea. Un deslizamiento rápido llega más lejos que uno lento, así que un gesto brusco recorre mucho camino mientras que un deslizamiento lento y cuidadoso mueve exactamente un carácter por paso.

## Seleccionar texto
Mantén pulsado Shift con un dedo y desliza con otro para seleccionar texto a partir del cursor. Puedes levantar el dedo que desliza y volver a deslizar para ampliar la misma selección. Pulsar o soltar Shift en mitad de un deslizamiento cambia entre seleccionar y mover el cursor sin más.

Una vez seleccionado algo, puedes copiarlo, borrarlo, envolverlo entre paréntesis, indentarlo o comentarlo con las teclas de arriba.

## Autocompletado
Mientras escribes aparece una lista de opciones de autocompletado. Desliza hacia arriba o hacia abajo para moverte por la lista y luego pulsa Tab o toca la entrada para insertarla. Return también inserta la entrada si coincide con lo que has escrito hasta ahora. Si no, Return cierra la lista y empieza una línea nueva. Desliza de lado para cerrar la lista sin insertar nada.

## Distribuciones
La opción "Distribución del teclado" te permite cambiar entre QWERTY, QWERTZ y AZERTY.

## Sensación
"Respuesta de teclas" en las opciones decide cómo se siente y suena el teclado. **Clic + vibración** reproduce un sonido de tecla mecánica y vibra con cada pulsación, con un tic por cada paso del cursor mientras deslizas. **Vibración** hace lo mismo sin el sonido, **Clic** solo reproduce el sonido, **Silencio** no hace ninguna de las dos cosas, y las variantes **Clic del sistema** usan el sonido de clic del teclado de tu dispositivo en lugar del mecánico.
