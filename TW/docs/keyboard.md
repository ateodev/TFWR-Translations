# 遊戲內鍵盤
遊戲內建一個用來編寫程式碼的鍵盤。它把 Python 所需的全部符號放在同一頁上，並讓你透過滑動來移動游標、選取文字和挑選程式碼補全，這樣你就再也不用費力去點程式碼中的某個小位置了。

如果你比較想使用裝置本身的鍵盤，請在選項中將「鍵盤類型」設為「系統」。連接實體鍵盤時一律優先使用實體鍵盤，拔除後遊戲內鍵盤會重新出現。

## 輸入
**括號和引號**：`()`、`[]`、`{}` 和 `"` 鍵會插入成對的符號並把游標放在中間。如果你選取了文字，它們會改為把文字包起來並保持選取狀態，方便你再次包裹。長按括號鍵片刻，會彈出只含左括號或右括號的選項；長按 `"` 鍵則會彈出單引號。滑到想要的那個再放開。

**Tab**：縮排一層。選取多行時會全部縮排。Shift + Tab 則是減少一層縮排。

**註解**（`#`）：將目前這一行或所有選取的行註解掉，如果已經是註解則取消註解。

**復原、重做、複製和貼上**的用法和你想的一樣。複製和貼上使用裝置的剪貼簿，所以你可以從其他應用程式貼上程式碼。重做、複製和貼上在沒有可操作內容時會變暗。

## 移動游標
在鍵盤上滑動可以移動游標。除了 Shift 和刪除鍵，任何按鍵都可以：只要手指按著，鍵盤就會變成觸控板。橫向滑動每次移動一個字元，上下滑動則可換行。快速滑動比慢速滑動走得更遠，所以輕輕一甩可以移動很長一段距離，而慢慢仔細地滑動則每步正好移動一個字元。

## 選取文字
用一根手指按住 Shift，再用另一根手指滑動，就能從游標處開始選取文字。你可以抬起滑動的手指再滑一次，以擴展同一段選取範圍。在滑動過程中按下或放開 Shift，可以在選取和一般游標移動之間切換。

選取內容後，你可以用上面的按鍵複製、刪除、加上括號、縮排或註解它。

## 程式碼補全
輸入時會彈出一份補全清單。上下滑動可以在清單中移動，然後按 Tab 或點選項目來插入它。如果項目和你已輸入的內容相符，按 Return 也會插入它。否則 Return 會關閉清單並開始新的一行。橫向滑動可以關閉清單而不插入任何內容。

## 配置
「鍵盤配置」選項可以在 QWERTY、QWERTZ 和 AZERTY 之間切換。

## 手感
選項中的「按鍵音」決定按鍵時的聲音：**機械**播放機械鍵盤按鍵聲，**系統**使用裝置鍵盤本身的按鍵聲，**靜音**則不播放任何聲音。「鍵盤音量」調整按鍵音的音量。「按鍵震動」會在每次按鍵時短暫震動，滑動時游標每移動一步也會輕震一下。

「背光」會像電競鍵盤一樣從下方照亮按鍵：**白色**發出白光，**RGB**發出彩虹色的光，每按一個鍵都會擴散出一圈光波。**關閉**則讓按鍵不發光。
