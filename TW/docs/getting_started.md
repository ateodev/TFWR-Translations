# 入門指南
<desktop>這個視窗包含了遊戲中所有內容。

拖動視窗的灰色部分可以移動視窗。
在視窗外任意處拖動可以移動鏡頭。

要開始編寫程式碼了嗎？請前往[第一個程式](docs/first_program.md)頁面。

看見螢幕右上角的按鈕了嗎？將滑鼠移到按鈕上就可以看到按鈕的作用了。其中一個按鈕可以開啟科技樹！
</desktop>
<mobile>這個視窗包含了遊戲中所有內容。

視窗會以全螢幕方式開啟。視窗標題列中的按鈕可以把它縮小成小視窗，也可以再次讓它填滿螢幕。拖動小視窗的灰色部分可以移動它。
在視窗外任意處拖動可以移動鏡頭，並用兩指縮放。

要開始編寫程式碼了嗎？請點選連結前往[第一個程式](docs/first_program.md)頁面。

看見螢幕底部邊緣的按鈕了嗎？橫握裝置時它們位於右上角。試著點選它們，看看有什麼作用。其中一個按鈕可以開啟科技樹！
</mobile>
