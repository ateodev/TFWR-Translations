# 珍珠岩與壤土

有些植物在透氣或養分豐富的土壤上產量更高。這個解鎖項新增了兩種地底方塊：珍珠岩和壤土（`Grounds.Perlite` 和 `Grounds.Loam`）。

這些新方塊類型以薄層形式出現在地底，類似黏土。

珍珠岩適合喜歡透氣土壤的植物：仙人掌、竹子、灌木和樹木。這些植物種在珍珠岩上時產量加倍。

壤土適合胡蘿蔔和向日葵。種在那裡時產量加倍。

珍珠岩和壤土的另一個優點是，種植適合這些土壤的作物前不需要呼叫 `till()`。
