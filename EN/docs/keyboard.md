# In-Game Keyboard
The game comes with its own keyboard for writing code. It puts all the symbols Python needs on a single page and lets you move the cursor, select text and pick code completions by swiping, so you never have to aim for a tiny spot in your code.

If you would rather use your device's own keyboard, set "Keyboard Type" to "System" in the options. A connected hardware keyboard is always used instead, and the in-game keyboard comes back when you disconnect it.

## Typing
**Brackets and quotes**: the `()`, `[]`, `{}` and `"` keys insert the pair and put the cursor in between. If you have text selected, they wrap it instead and keep it selected, so you can wrap it again. Hold a bracket key for a moment to get a popup with just the opening or the closing bracket, slide to the one you want and let go.

**Tab**: indents by one level. With several lines selected it indents all of them. Shift + Tab removes one level of indentation instead.

**Comment** (`#`): comments out the current line, or every selected line, and uncomments them when they already are.

**Undo, redo, copy and paste** work as you would expect. Copy and paste use your device's clipboard, so you can paste code from other apps. Redo, copy and paste are dimmed when there is nothing for them to do.

## Moving the cursor
Swipe on the keyboard to move the cursor. Any key works except Shift and Delete: the keyboard turns into a trackpad for as long as your finger is down. Swipe sideways to move one character at a time and up or down to change lines. A fast swipe travels further than a slow one, so a flick covers a lot of ground while a slow, careful swipe moves exactly one character per step.

## Selecting text
Hold Shift with one finger and swipe with another to select text starting from the cursor. You can lift the swiping finger and swipe again to extend the same selection. Pressing or releasing Shift in the middle of a swipe switches between selecting and plain cursor movement.

Once something is selected you can copy it, delete it, wrap it in brackets, indent it or comment it out with the keys above.

## Code completion
While you type, a list of completions pops up. Swipe up or down to move through the list, then press Tab to insert the highlighted entry. Return also inserts the entry if it matches what you have typed so far. Otherwise it closes the list and starts a new line. Swipe sideways to close the list without inserting anything.

## Layouts
The "Keyboard Layout" option allows you to switch between QWERTY, QWERTZ and AZERTY.

## Feel
"Key Switches" in the options decides how the keyboard feels and sounds, named after mechanical keyboard switches. **Tactile** switches vibrate on every key press and tick for every cursor step while you swipe, **Clicky** switches play a key sound, **Linear** switches do not vibrate, **Silent** ones make no sound, and the **OS** variants use your system keyboard's click sound instead of the mechanical one.
