# Import and Export
You can take a save out of the game as a file, and bring one in. Both are part of the full game: in the free trial, pressing either one opens the window where you can get it.

## Export
On the load screen, tap the three dots on a save's card and choose 'Export'. The game makes a zip of that save, and you choose where it goes.

Keep it as a copy of your own, or carry the save to the PC game: unzip it into a folder of its own in the PC game's Saves folder.

## Import
Press 'Import' on the load screen and choose a zip of a save. Some devices also let you choose a save's folder. A save can be up to 1 MB. An import always makes a new save and never replaces one.

When a save can't come in as it is, the load screen tells you why:

**Please update the game**: the save comes from a newer version of the game. Update the game on this device to import it.

**This save comes from an older version**: update the game on your PC, load this save there and save it once. Then copy it to this device and import it again.

**This save was imported with changes**: the save held unlocks, items or data this version of the game doesn't know or allow. They were left out or lowered, and the notice lists what changed.

## Cloud save
Cloud save keeps your devices on the same progress. An exported file is your own, kept where you choose.
